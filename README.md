# Google Search Trends Analysis

## Overview

This project analyzes Google search trends using Python and Pytrends to understand search interest for popular dog breeds.

The analysis focuses on **Golden Retriever** and also compares its search interest with **Siberian Husky** and **German Shepherd**.

## Objectives

- Analyze Google search interest for Golden Retriever
- Identify countries with the highest search interest
- Visualize geographic search interest
- Analyze search interest over time
- Compare search trends between different dog breeds
- Create meaningful visualizations using Python

## Technologies Used

- Python
- Pandas
- Pytrends
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Analysis Performed

### 1. Country-wise Search Interest

The project identifies the countries showing the highest search interest for **Golden Retriever** during the selected time period.

### 2. Geographic Visualization

A geographic visualization is created to represent search interest across countries.

### 3. Search Interest Over Time

The project analyzes how search interest for Golden Retriever changes over a 12-month period.

### 4. Keyword Comparison

Search trends are explored for:

- Golden Retriever
- Siberian Husky
- German Shepherd

This helps understand differences in search interest between the selected dog breeds.
